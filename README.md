# 🌐 Sistema WEB

Sistema web desenvolvido como parte de um projeto acadêmico realizado durante o CEP.

O projeto tinha como objetivo desenvolver uma aplicação para auxiliar no **gerenciamento de salas**, contando também com funcionalidades de cadastro e navegação entre diferentes áreas do sistema.

> ⚠️ **Status do projeto: Descontinuado**
>
> O desenvolvimento foi interrompido por decisão do professor responsável pela atividade. Por esse motivo, algumas funcionalidades não foram finalizadas e o sistema possui limitações conhecidas.

---

## 📌 Sobre o projeto

Durante o desenvolvimento, foram criadas diferentes páginas para compor a aplicação, incluindo funcionalidades relacionadas a:

* 👤 Cadastro de usuários;
* 🔐 Tela de login;
* 🏠 Página inicial;
* 🏫 Gerenciamento de salas;
* 📅 Agendamentos;
* 📚 Recursos;
* ℹ️ Informações sobre o sistema.

Parte das funcionalidades permanece funcional, enquanto outras ficaram incompletas devido à interrupção do projeto.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap
* LocalStorage

---

## 💾 Armazenamento

O projeto utiliza o **LocalStorage do navegador** para armazenar algumas informações.

Essa abordagem foi utilizada considerando o contexto acadêmico do projeto e as limitações do desenvolvimento.

**Importante:** o `LocalStorage` não é uma solução adequada para armazenar informações sensíveis ou para uma aplicação de produção, pois os dados ficam armazenados localmente no navegador e não existe uma estrutura de backend e banco de dados para controlar essas informações de forma adequada.

Em uma futura continuação do projeto, essa parte poderia ser substituída por uma arquitetura envolvendo:

* Backend;
* Banco de dados;
* Autenticação adequada;
* API para comunicação entre frontend e backend.

---

## ⚠️ Limitações conhecidas

Como o projeto foi descontinuado antes da conclusão, algumas limitações permanecem:

* A funcionalidade principal de gerenciamento de salas possui algumas falhas;
* Algumas funcionalidades não foram finalizadas;
* O armazenamento é realizado através do LocalStorage;
* Não existe backend integrado;
* O sistema não deve ser considerado uma aplicação pronta para produção.
